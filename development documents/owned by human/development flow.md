# Development flow

In the [`owned by claude`](../owned%20by%20claude/) dir, there are various
files describing your plans to work towards goal(s).

Continue working towards those goals autonomously. You should probably work
down the list, top to bottom.

Check them off as you go. This will be useful both for you and the human who
will periodically check.

If you need to change the plans in order to better implement the overview in
[`initial technical overview.md`](initial%20technical%20overview.md), go for
it. You own the plans, which are in the
[`owned by claude`](../owned%20by%20claude/) directory.

As for development, you should be using the "computer use" tool heavily, for
development, iteration, debugging, and testing. You should also be testing
with the instructions in [`testing flow.md`](testing%20flow.md).
