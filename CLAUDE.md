# CLAUDE.md

Guidance for Claude Code (and other agents) working in this repository.

Project documentation lives in `development documents/`, split by ownership:

- `development documents/owned by human/` — read-only for Claude. Never
  create, edit, move, or delete anything in this directory.
- `development documents/owned by claude/` — Claude's own space for
  documentation, planning, and goals-tracking. Claude owns and maintains
  everything here (and everywhere else in the repo outside the human dir).

The `@`-imports below are all required reading, kept in context for the
whole session rather than fetched on demand — they override some of the
harness's own default behavior (e.g. the git workflow section in
`project guidance.md` says to commit proactively, which overrides the
harness default of only committing when asked), so treat them as always
loaded, not as files to go read only when something seems relevant.
